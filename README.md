# Data Science Learning

A structured collection of my hands-on learning and practice in Data Science with Python.

This repository documents my progress from fundamental numerical computing and data manipulation to data visualization, API integration, and web scraping. Each section contains practical notebooks and examples focused on building a strong foundation in data analysis.

## 📌 Overview

This repository is part of my ongoing journey toward becoming a data-focused software developer.

Instead of keeping practice work scattered across different files, I organized the concepts into separate sections so that my learning progress can be easily tracked and revisited.

### Topics Covered

- Numerical computing with NumPy
- Data manipulation and analysis with Pandas
- Data visualization with Matplotlib
- Statistical and advanced visualization with Seaborn
- API integration and data collection
- Web scraping fundamentals
- Working with real-world datasets
- Jupyter Notebook based analysis
